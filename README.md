A Pseudo Random Number Generator library built as a modern module without dependencies.

Check out [the documentation](https://statox.github.io/simple-prng.ts/).

The code is based on a port of the Mercenne Twister C Code from [this Wikipedia page](https://en.wikipedia.org/wiki/Mersenne_Twister#C_code).
adding some features.

The published [package on npm](https://www.npmjs.com/package/simple-prng) contains CommonJS, ECMAScript and UMD modules. So you should be able to use this package anywhere from nodeJS or deno backends to frontent applications using vanilla JavaScript or your favorite frontend framework like Svelte or React.
